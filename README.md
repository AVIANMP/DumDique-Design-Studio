# DumDique Design Studio

A responsive, single-page portfolio demo for testing SignaCRM's website connector.

## Local preview

Open `index.html` in a browser, or serve this directory with any static file server.

## GitHub Pages

The site is published from the repository's `main` branch, repository root. The SignaCRM connector is included in `index.html`; its domain settings may need to allow the published GitHub Pages URL.
